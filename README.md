# Git and GitHub Practical

## Introduction
Git is a distributed version control system used to
track changes in files and coordinate development.

GitHub is a cloud-based platform used to host Git
repositories and collaborate with developers.

## Objectives
- Understand Git and GitHub.
- Learn repository initialisation.
- Learn staging and committing.
- Understand branches and remote repositories.


## Git Commands Learned

1. git init - Initialize a repository.
2. git status - Check repository status.
3. git add - Stage changes.
4. git commit - Save changes.
5. git log - View commit history.
6. git show - View commit details.

## Conclusion
Git and GitHub help developers manage project versions,
track changes, and collaborate efficiently.
