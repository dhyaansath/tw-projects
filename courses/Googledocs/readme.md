# Google Docs

## Introduction
Google Docs is a free, web-based word-processing application
developed by Google. It allows users to create, edit, format,
and share documents online.

## Objectives
- Learn how to create and edit documents.
- Understand text formatting and page layout.
- Learn real-time collaboration.
- Understand document sharing and permissions.
- Explore version history.

## Key Features

### 1. Document Creation
Users can create new documents or edit existing files.

### 2. Text Formatting
Google Docs provides formatting options such as:
- Font style and size
- Bold, italic, and underline
- Text alignment
- Bulleted and numbered lists
- Headings and paragraphs

### 3. Real-Time Collaboration
Multiple users can work on the same document simultaneously.
Changes are automatically saved.

### 4. Sharing and Permissions
Documents can be shared with other users using:
- Viewer: Can only view the document.
- Commenter: Can view and add comments.
- Editor: Can make changes to the document.

### 5. Version History
Version history allows users to view previous versions
and restore earlier changes.

## Advantages
- Free and easy to use.
- Automatic saving.
- Accessible from different devices.
- Supports real-time collaboration.
- Documents can be exported in different formats.

## Conclusion
Google Docs is a useful tool for creating and managing
documents. Its collaboration, automatic saving, and
sharing features make it suitable for academic and
professional work.
