# Git & GitHub Whitepaper
Git tracks changes to files over time, ensuring accountability and supporting parallel development via branching.
## Key Commands:
- `git init`: Initializes a repo.
- `git add <file>`: Stages changes.
- `git commit -m "msg"`: Records a snapshot.
- `git branch` & `git merge`: For parallel feature development.
- `git push` & `git pull`: Sync with a remote repository (like GitHub).
