# LaTeX Whitepaper
LaTeX is an industry-standard document preparation system. It separates content from formatting.
## Key Features:
- **Document Classes:** `article`, `report`, `book`, `letter`.
- **Mathematical Typesetting:** Excellent support for math formulas (inline `$x^2$` and display `\[ E=mc^2 \\]`). Includes arrays, matrices (`bmatrix`, `pmatrix`), fractions, and integrals.
- **Tables and Figures:** Use `tabular` for tables and `graphicx` for images.
- **Cross-Referencing:** Built-in `\label` and `\ref` commands.
